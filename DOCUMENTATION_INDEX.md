## 💡 Quick Tips

### Tip 1: Keep CHEAT_SHEET.md Open
It has all the line numbers and quick references you need.

### Tip 2: Copy-Paste from EXAMPLES
Don't type from scratch - copy examples and modify them.

### Tip 3: Check TROUBLESHOOTING First
Most problems are already documented with solutions.

### Tip 4: Make One Change at a Time
Easier to debug if something goes wrong.

### Tip 5: Test After Every Edit
Don't make 10 changes before testing!
